# VaultGov AI

VaultGov AI is a secure government vaults AI platform.

## Directory Structure
- `mobile/`: Mobile application client (React Native skeleton).
- `backend/`: Backend service application (FastAPI skeleton).
- `database/`: Database migrations and seeds.
- `docs/`: Project documentation and guidelines.
- `api-contracts/`: API contract specifications.
- `assets/`: Global design and media assets.
- `scripts/`: Development and deployment helper scripts.

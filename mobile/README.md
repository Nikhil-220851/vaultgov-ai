# Mobile Application Client

This directory contains the source code for the mobile client.

## Folder Structure
- `src/`: Core source files.
  - `screens/`: UI screen components.
  - `components/`: Reusable UI components.
  - `navigation/`: Routing and navigation configuration.
  - `services/`: API and third-party service clients.
  - `hooks/`: Custom React hooks.
  - `context/`: React context providers.
  - `constants/`: Theme variables, API endpoints, static configuration.
  - `utils/`: Helper utility functions.
  - `assets/`: App-specific assets (images, fonts, local icons).

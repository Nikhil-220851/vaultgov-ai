# Backend Service

This directory contains the backend application source code.

## Folder Structure
- `app/`: Main FastAPI application package.
  - `api/`: API router endpoints and controllers.
  - `services/`: Business logic services.
  - `models/`: Database Models (ORM definitions).
  - `schemas/`: Pydantic schemas for request/response validation.
  - `database/`: Database session setup and connection logic.
  - `core/`: Core config, security settings, exceptions, constants.
  - `tests/`: Automated unit and integration tests.
